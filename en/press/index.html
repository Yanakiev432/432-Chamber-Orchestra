432 Chamber Orchestra is an independent string orchestra based in Sofia, returning with a model built around disciplined string sound, recordings, archive, public documentation, and a listening community that follows the work beyond one evening.

Key facts

  • Independent string orchestra based in Sofia
  • Legal and organisational structure: Foundation 432 Hertz
  • Founder: Ivan K. Yanakiev, PhD
  • Current campaign: The First Sound Again
  • First documented output: presentation, recording/documentation where possible, archive/project page, and short report
  • Larger return frame: 60+ minute full string-orchestra programme
