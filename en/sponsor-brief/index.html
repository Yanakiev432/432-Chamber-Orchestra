Sponsor brief

432 Chamber Orchestra

The First Sound Again · brief for companies, patrons, and partners

Who we are

432 Chamber Orchestra is an independent string orchestra based in Sofia. Foundation 432 Hertz is the legal and organisational structure behind the orchestra.

Founder

Ivan K. Yanakiev, PhD is the founder of 432 Chamber Orchestra. His work brings together conducting, string-orchestra discipline, research, documentation, and the previous history of the orchestra.

Why now

The return should produce a documented artistic result: work, recording, archive trace, accountability, and a next orchestral phase.

The First Sound Again

The first mobilisation campaign begins with a listening community and serious conversations with companies, hosts, and patrons.

First documented step

The first supportable phase is a compact working step with musician fees, rehearsal work, documentation, and an archive/project page.

Full orchestra return programme

The larger return phase is conceived as a full string-orchestra programme of 60+ minutes.

This is not a confirmed concert announcement yet. It is a working programme frame for the first substantial orchestral return of 432 Chamber Orchestra.

The programme should make a serious artistic argument: Bulgarian contemporary sound, classical solo form, English string-orchestra discipline, and Bulgarian modern chamber memory brought into the context of a restored string-orchestra body.

  • Gheorghi Arnaoudov — Gates of Dream II
  • Joseph Haydn — Cello Concerto in C major; soloist to be invited / to be confirmed
  • Edward Elgar — St Paul’s Suite
  • Lyubomir Pipkov — String Quartet No. 1; orchestral format / arrangement status to be confirmed

Final programme, order, duration, venue, date, instrumentation, soloist, rights, and arrangement status remain to be confirmed.

Funding target

The return should be funded as a defined artistic output, not as a vague appeal.

The project should not be budgeted as “a concert”. It should be budgeted as a documented artistic production: rehearsal, performance, rights, recording, documentation, PR, archive, and reporting.

  • Minimum first phase — 30,000 EUR. Covers a lean but professional documented return step, with constrained documentation and limited PR. It should still protect musician fees, core rehearsal work, essential rights/licensing checks, basic recording, archive page, and reporting.
  • Professional target — 55,000 EUR. Covers the recommended 60+ minute full string-orchestra return programme with soloist invitation, fair musician fees, rehearsal work, score/arrangement preparation, rights/licensing, professional audio, multi-camera documentation, photography, PR, archive/project page, administration, and reporting.
  • Full return phase — 90,000 EUR. Covers a stronger public production with extended documentation, stronger PR/media campaign, higher-level soloist conditions, larger venue conditions, stronger post-production, broader campaign visibility, and stronger institutional reporting.

What the professional target includes

  • 13 instrumentalists
  • soloist invitation
  • conductor / artistic preparation
  • concertmaster and section responsibility
  • orchestra manager / librarian / production assistant
  • rehearsal work
  • venue and production logistics
  • rights, licensing, scores, and arrangements
  • professional audio recording, editing, and mastering
  • multi-camera video documentation
  • photography
  • PR strategy and media outreach
  • design, copywriting, translation, programme note
  • paid promotion where appropriate
  • posters, print, and distribution
  • website/archive page and post-project report
  • contracts, accounting, administration
  • contingency

What support funds

  • invitation of a strong soloist
  • musician fees
  • rehearsal work
  • score and arrangement preparation where needed
  • recording and editing
  • photo/video documentation
  • archive/project page
  • short post-project report

Support levels

  • Musician Fee Patron — 500–1,000 EUR. Supports fair musician fees and rehearsal work.
  • Recording Patron — 1,500–3,500 EUR. Supports audio recording, editing, mastering, and archive preparation.
  • Soloist Invitation Patron — 3,000–5,000 EUR. Supports soloist invitation and conditions; the soloist remains to be confirmed.
  • Score & Rights Patron — 2,000–4,000 EUR. Supports scores, arrangements, rights, and licensing where needed.
  • Full Documentation Partner — 7,500–12,000 EUR. Supports professional audio, video documentation, photography, and archive page.
  • Principal Concert Partner — 15,000–25,000 EUR. Supports a substantial part of production, rehearsals, communication, and documentation.
  • Founding Return Patron — 50,000–55,000 EUR. Supports the professional target and the recommended 60+ minute full string-orchestra programme.
  • Full Return Partner — 85,000–90,000 EUR. Supports the full return phase with stronger production, documentation, visibility, and reporting.

Reporting and accountability

Support should lead to a defined artistic result.

  • a defined project scope
  • a clear budget line or support purpose
  • documentation of the artistic work
  • an archive or project page where appropriate
  • a short post-project report for supporters and partners
